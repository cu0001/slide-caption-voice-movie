# IBM Bobで使う

[はじめての方は README へ](../README.md)

IBM Bobでこのプロジェクトのフォルダーを開き、同じPCにNode.js・npm・Google Chromeを用意します。Bobは制作のためのファイル操作とコマンド実行を担当し、アプリの再生・編集・動画の書き出しはChromeで行います。Bob専用のパッケージや、アプリへのAPIキー設定は不要です。ナレーションを付ける場合は、先に「[ナレーションの準備](../README.md#2-ナレーションの準備irodori-tts)」を済ませてください。

## 1. フォルダーを開いて起動する

1. IBM Bobで、`README.md` と `package.json` が入っているフォルダーを開きます。
2. Bobのターミナルで `node -v` と `npm -v` を実行し、前提条件を満たしているか確認します。
3. 初回は `npm ci` を実行し、続けて `npm run dev` を実行します。
4. 表示されたURLをChromeで開きます。デモはURLの末尾に `/?sample=demo` を付けると表示されます。

PDFから動画を作るときは、Bobのチャットを **Agentモード** にします。Askモードは読み取り専用です。操作方法は [IBM Bob公式クイックスタート](https://bob.ibm.com/docs/ide/getting-started/quickstart) を参照してください。ファイル変更やコマンド実行の承認が表示されたら、対象と内容を確認して進めます。

## 2. Bobに制作を依頼する

次の依頼文を、そのままBobのチャットに貼り付けてください。自分の資料を使う場合は、PDFのパスを置き換えます。

```text
user-test/coffee-break.pdf をナレーションと字幕付きの動画にしてください。動きはなるべく多めにしてください。
```

## Bobでの制作手順の読み替え

制作手順書（スキル）は `.claude/skills/` にありますが、中で使うnpmコマンドはこのプロジェクト共通のものです。**Bobは `.claude/skills/` の手順書を標準で読み取れるので、依頼文でパスを指定する必要はありません。**

| 手順書の記載 | IBM Bobでの進め方 |
|---|---|
| `Read` でPDF・画像を見る | Bobで利用できるPDF・画像の読み取り機能で内容を確認します。PDFを直接読めない場合は、`captions:export` のページ画像と、必要に応じてPDFから抽出した本文を使います |
| `Bash` でnpmコマンドを実行する | Bobのターミナル・コマンド実行機能を使います。Windowsでも記載のnpmコマンドを使えます |
| `.claude/launch.json`・`preview_start`・`mcp__Claude_Browser__*` | Bobのターミナルで `npm run dev` を起動し、表示されたURLをChromeで開きます |
| `run_in_background` | 開発サーバー用のターミナルを開いたままにし、制作コマンドは別のターミナルで実行します |
| 専用の通知ツール | 利用できない場合は、Bobのチャットで完了・失敗と保存先を報告します |

画像を読み取れない環境では、部品の位置や字幕の内容を十分に確認できません。画像を確認できる環境に切り替えてから制作してください。また、CLIはPlaywright経由で**インストール済みのGoogle Chrome**を起動します。Chromeを起動できるローカル環境で実行してください。

## Bobに動きや音声の修正を頼む

画面で字幕を編集した場合は、先に「保存」で最新のJSONを保存し、そのファイルを指定します。

```text
output/coffee-break/coffee-break-voice.json の、2枚目の太陽をもう少しゆっくり登場させてください。
起動時のプロジェクトを更新して、WebMも書き出し直してください。
```

```text
保存した coffee-break-voice.json で字幕を直しました。音声を作り直して、WebMも書き出し直してください。
```

ここで説明するBob向け手順は、既存のnpmコマンドを利用する方法です。IBM Bob上での一連の操作は未検証のため、利用するバージョン・モデル・実行権限によって操作が異なる場合があります。
